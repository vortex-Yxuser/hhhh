# HHHH SSH VPN Pro v2.0

**نسخة مطوّرة ومحسّنة** من مشروع SSH Payload VPN — تركيز كامل على **السرعة** و**استقرار السجلات (Logs)**.

## التحسينات الرئيسية مقارنة بالنسخة الأصلية

### 🚀 السرعة (Speed)
- استخدام **JSch الحديث** (`com.github.mwiede:jsch:0.2.20`) مع خوارزميات أسرع (curve25519, aes-gcm, chacha20...).
- تفعيل `TCP_NODELAY` + buffers كبيرة (256KB).
- إعداد tun2socks محسّن (`multi-queue`, task-stack-size).
- مهلات اتصال مضبوطة وتقليل الانتظار غير الضروري.
- خيط عمل بأعلى أولوية + thread pool لـ SOCKS.

### 📋 استقرار السجلات (Stable Logs)
- طوابع زمنية دقيقة لكل رسالة.
- استخدام Broadcast مع package filter لتجنب الضياع.
- Auto-scroll مستقر بدون تجميد الواجهة.
- رسائل واضحة مع رموز (✓ ✗ ▶ ○ ✅).
- لا تسقط السجلات حتى تحت الضغط.

### ميزات إضافية
- واجهة داكنة كاملة + حقول قابلة للتعديل للـ Payload والبروكسي.
- 5 قوالب Payload جاهزة (Snapchat / YouTube / Generic / Fast / Manual).
- دعم بروكسي وسيط كامل من الواجهة.
- استبعاد التطبيق نفسه من VPN لتجنب الحلقات.
- بناء تلقائي على GitHub Actions ينتج APK جاهز.
- hev-socks5-tunnel يُجلب ويُبنى تلقائياً.

## الاستخدام السريع

1. ارفع الكود إلى هذا المستودع (أو اعمل fork).
2. اذهب إلى تبويب **Actions** → انتظر انتهاء البناء.
3. حمّل الـ APK من Artifacts.
4. ثبّته وأدخل بيانات SSH الخاصة بك + Payload إن أردت.

## البناء المحلي
يحتاج Android Studio + NDK 25.2.x  
`./gradlew assembleDebug`

المطور لا يوفر أي خوادم SSH.
